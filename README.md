# Sistema Gerenciador de Academia (FitSystem)

Sistema integrado para controle de alunos, matrículas e fichas de treino da academia.

## Estrutura do Repositório
* `cliente.py`: Módulo de cadastro e gestão de status de alunos.
* `treino.py`: Módulo de cálculo de gasto calórico e rotinas.

## Execução
Certifique-se de configurar o arquivo `.gitignore` antes de iniciar o banco de dados local para evitar o versionamento de dados sensíveis.
